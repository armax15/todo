# Добро пожаловать в Task Manager!

Task Manager - это современное веб-приложение для управления личными задачами. В этой статье мы расскажем, как начать использовать приложение и получить максимум от его возможностей.

## Создание аккаунта

Для начала работы вам нужно создать аккаунт. Мы предлагаем два способа регистрации:

1. **Email** - зарегистрируйтесь с помощью электронной почты
2. **Google** - используйте ваш Google аккаунт для быстрой регистрации

## Создание первой задачи

После регистрации вы попадете на главную страницу приложения. Чтобы создать свою первую задачу:

1. Нажмите кнопку "Создать задачу"
2. Введите название задачи
3. (Опционально) Добавьте описание
4. (Опционально) Установите приоритет и срок выполнения
5. Нажмите "Создать"

## Управление задачами

Вы можете:

- ✅ Отмечать задачи как выполненные
- ✏️ Редактировать существующие задачи
- 🗑️ Удалять ненужные задачи
- 🔍 Фильтровать задачи по статусу

## Советы для эффективной работы

### 1. Используйте приоритеты

Устанавливайте приоритеты для ваших задач:
- **High** - срочные и важные задачи
- **Medium** - важные, но не срочные
- **Low** - задачи, которые можно сделать позже

### 2. Разбивайте большие задачи

Если задача кажется слишком большой, разбейте её на несколько маленьких. Это поможет вам лучше отслеживать прогресс.

### 3. Проверяйте задачи регулярно

Выделите время в начале и конце дня для проверки списка задач. Это поможет вам оставаться организованными.
